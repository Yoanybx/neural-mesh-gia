1. **N=2 multi-node packaging beyond single-node**  
   Package / document the existing N=2 CRAM replica path as an optional
   multi-node bundle beyond the frozen single-node RC. Stay inside Phase
   5A/5B N=2 interfaces. **No N>2**, no Raft, no multi-primary.

2. **Fabric ops UX**  
   Operator-facing UX around existing TLS network fabric helpers. Status /
   diagnose / reconnect ergonomics; no Vault/ACME hard requirement; no
   silent plaintext.

3. **Richer OBS peers**  
   Extend `mesh.status.snapshot/v1` injection ergonomics for peer summaries.
   Optional read-only peer probe only if existing fabric helpers allow a
   trivial call — still **no consensus**, no Raft, no N>2.

4. **External quickstart**  
   Public/external quickstart for the signed-off **0.16.3** single-node
   bundle, plus a forward-looking 0.17 quickstart stub pointing at themes
   above without shipping unfinished features.
