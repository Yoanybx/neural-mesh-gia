## Purpose

Propose honest themes for a future **0.17.x** minor line grounded in repo reality
after single-node RC closeout (Cycles 20–24 / CP-0024–CP-0028). This document
does **not** authorize code for 0.17.0.

## Proposed themes (candidates)

### 1. Multi-node packaging beyond single-node (N=2 track only)

- Package / document the existing **N=2 CRAM replica** path as an optional
  multi-node bundle *beyond* the frozen single-node RC.
- Stay inside existing Phase 5A/5B N=2 interfaces; **no N>2**, no Raft, no
  multi-primary.
- Manifest channel decision deferred (likely `0.17.x` with additive schema or
  a sibling product name) — **planning only**.

### 2. Fabric ops UX

- Operator-facing UX around existing TLS network fabric helpers
  (`docs/network_fabric_tls.md`, Cycle 11 capability).
- Status / diagnose / reconnect ergonomics for local fabric; no Vault/ACME
  hard requirement; no silent plaintext.

### 3. Richer OBS peers

- Extend `mesh.status.snapshot/v1` **injection** ergonomics for peer summaries
  (already caller-injected; peers=0 in single-node RC).
- Optional read-only peer probe only if existing fabric helpers allow a trivial
  call — still **no consensus**, no Raft, no N>2.

### 4. External quickstart

- Public/external quickstart for the signed-off **0.16.3** single-node bundle
  (extract → `mesh status` → smoke), plus a forward-looking 0.17 quickstart
  stub that points at themes above without shipping unfinished features.
